Política de privacidad de BariSnow

Última actualización: 11 de agosto de 2026
BariSnow es una aplicación meteorológica orientada a nieve, temperatura y condiciones de corto plazo en San Carlos de Bariloche y zonas cercanas.

Datos personales

BariSnow no requiere crear una cuenta y no solicita acceso a contactos, mensajes, cámara, micrófono, ubicación precisa del dispositivo ni almacenamiento personal.

Zona seleccionada

La aplicación permite elegir zonas predefinidas de Bariloche. La zona elegida se guarda localmente en el dispositivo para mantener sincronizados la aplicación y los widgets. No se utiliza la ubicación GPS del usuario.

Datos meteorológicos y servicios externos

Para obtener pronósticos, BariSnow realiza solicitudes HTTPS a servicios meteorológicos externos, actualmente Open-Meteo, usando las coordenadas de la zona predefinida seleccionada. Como ocurre con cualquier conexión de red, el proveedor puede recibir datos técnicos de la conexión, como la dirección IP, de acuerdo con sus propias políticas.

La interfaz web de BariSnow se publica mediante GitHub Pages. La aplicación Android puede cargar esa interfaz dentro de un WebView.

Publicidad

La versión 1.4.0 se prepara técnicamente para una futura integración publicitaria, pero la publicidad y AdMob permanecen desactivados. Antes de activar anuncios se actualizará esta política, la declaración de seguridad de datos de Google Play y, cuando corresponda, el mecanismo de consentimiento aplicable.

Conservación y transferencia

BariSnow no mantiene una base propia de perfiles de usuarios. Las preferencias locales pueden eliminarse desinstalando la aplicación o borrando sus datos desde Android.

Menores

BariSnow es una utilidad meteorológica de uso general y no está diseñada para recopilar información personal de menores.

Cambios

Esta política puede actualizarse si cambian las funciones, proveedores o prácticas de tratamiento de datos. La fecha de actualización se indicará al comienzo de esta página.
